- **PARTIAL**: ทำบางส่วนได้ แต่ขาด behavior/options/guards ที่ระบุอย่างชัดเจน.
- **MISSING**: ไม่พบ UI + backend workflow ใน `native/src` และ `crates/xen-core/src` สำหรับ capability นี้. Generic helpers/record display ไม่ถูกนับแทน workflow.

จำนวน capability rows: **78** — IMPLEMENTED 19, PARTIAL 27, MISSING 32. เป็นจำนวนแถวที่แบ่งตามพฤติกรรม ไม่ใช่เปอร์เซ็นต์ parity ของผลิตภัณฑ์ และไม่บวกกับจำนวน source files ใน appendix.

## สิ่งที่กระทบผู้ใช้มากที่สุด

1. VM migration/cross-pool copy/move และ import/export ยังไม่มีจริง: `VDI.pool_migrate` ที่มีอยู่ย้ายแค่ disk ไม่ได้ย้าย VM ไป host อื่น.
2. ปุ่ม New VM from template คือ clone+provision ตาม template เดิม ยังไม่มี full wizard สำหรับ CPU/RAM/SR/network/install media/cloud config.
3. Manual snapshot มีเฉพาะ disk snapshot: ไม่มี checkpoint, quiesce, description/screenshot หรือ snapshot→new VM/template workflow.
4. VM resource editing ยังต้องหยุด VM ในหลายกรณีที่ต้นฉบับรองรับ live operation เช่น vCPU hotplug และ online disk grow.
5. Storage wizard/backend breadth ขาดมาก: create/probe/reattach เน้น file-backed path; NFS/iSCSI/HBA/FCoE/ISO/CIFS discovery/creation ไม่เทียบเท่าต้นฉบับ.
6. GPU/USB assignment, PV-tools installation, CPU topology/weight, VM autostart/PV args, startup order และ SR default/read caching ยังไม่มี.
