# Xen Desktop 0.2.0

This milestone brings the desktop layout closer to XCP-ng Center.

- A menu bar, toolbar, and status bar put management commands in familiar places.
- The navigation tree and view modes organize servers, VMs, templates, storage, and networks.
- Each object has its own tabs, with a Search tab for finding and opening resources.
- Context menus and multi-select let you act on selected resources together.
- Notifications has separate Alerts and Events views, with alert dismissal, event filters, and CSV export.
- The Add Server dialog focuses the Host field when it opens, with Unicode copy and paste verified on Linux.

## Known gaps

- Some management commands remain unavailable. Permissions, directory authentication, and certificate commands remain disabled.
- The Virtual Disks tree group and grouping result pages are incomplete. Creating a standalone virtual disk from a storage repository is unavailable.
- Storage Move, NIC Rescan, Delete Bond, IP Configure, and the host Console remain unavailable. Network creation excludes the sole management NIC, and Pool and Server menus lack a New Network entry.
- Memory shows allocated memory. Search lacks CPU usage, guest used memory, guest addresses, and uptime. Several other table fields are unavailable.
- Template editing, hot-add, disk position, and some disk property controls remain limited. Exact command availability still differs from XCP-ng Center.
- Some PBD and NIC controls have no visible entry point. Storage Detach lacks the upstream check for running VMs.
- Help contains outdated migration text. The SSH dependency reports a future Rust compatibility warning.
- Alert dates depend on the server clock. The test server was seven hours ahead, so correctly converted alerts could appear in the future. A test VM clone also required a refresh of stale allowed operations.

Live verification remains incomplete for multiple servers, disconnected resources, folder and custom-field views, saved searches, and some pool and hardware tabs. VM creation through the interface, most batch operations, export, snapshot revert, other disk and network changes, bond creation, and saving pool or network options were not fully exercised. VM Console and Performance behavior also need further live checks.

Notification checks did not cover a single task through both running and completed states, cancellation, bulk dismissal, every filter, the 1,000-event limit, or status-bar navigation from another page. Final Events table changes lack updated screenshots. Earlier checks also left history, theme, zoom, toolbar visibility, keyboard shortcuts, and table context-menu paths untested. Host Power On availability needs capability and liveness verification.
