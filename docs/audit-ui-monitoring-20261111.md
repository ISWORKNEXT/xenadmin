# UI, monitoring, consoles and settings parity audit — 11 November 2026

Upstream pinned at `ba43130ffb30d05d1eb40187b8ef9f2de111468a` (`development`); local pinned at `bec2480623267555c362ff0b7987ea929ec36050` (`development`). Source comparison only in this document; no Xen host contacted and no mutation performed. Runtime/test results belong to the parent audit report.

This inventories all 22 non-Designer source files under upstream `XenAdmin/TabPages` (20 concrete pages + 2 infrastructure bases), all 8 concrete `OptionsPages`, the UI/monitoring settings panels, and all 34 diagnostics source files including the abstract base file. It is not a claim that every C# method has a one-to-one Rust equivalent. Rows represent user-visible capabilities or diagnostic checks; broad screen rows and finer capability rows overlap and must not be added to infer a product completeness percentage.

Status: **Implemented** = the named narrow source behavior exists, with no claim of whole-feature equivalence or runtime proof; **Partial** = counterpart exists with stated missing behavior; **Missing** = no corresponding implementation found in current native/core sources; **Infrastructure** = helper/base, excluded from feature completeness.

Rows: 107; Implemented: 6, Infrastructure: 3, Missing: 46, Partial: 52.

## Most material gaps

- No custom performance graph CRUD/layout persistence, VM message overlays, or 1-week/month/year chart ranges.
- No typed-alert fix actions, rich alert/history filtering/export, resource-report export or perfmon SMTP/threshold editing.
- Embedded VNC/RDP/SSH exists. Remaining console gaps include undock/fullscreen, automatic RDP switching, settings and RDP redirection; do not mark all embedded RDP/SSH missing as the old gap doc does.
- Search supports boolean VM/template queries and local saved searches, but lacks arbitrary object search, import/export compatibility and upstream grouping/folder workflows.
- The local set of 34 cached diagnostics is a different set from upstream upgrade/DR checks. Identical counts provide no parity evidence.
